Fenix Spoon 🥄 — heat sink, with the controls built from the solver's own schema

Aluminium fins on a base, heated from below by a chip and cooled by air moving over every exposed surface. Nothing below the geometry sliders is written by this page: the parameter form is generated from the params_schema that GET /api/v1/solvers returns, so a solver that gains a parameter gains a control here without anyone editing HTML. Add fins and watch the chip temperature fall.

The widget bundles aren't built. Run npm --prefix client install && npm --prefix client run build, then reload.
