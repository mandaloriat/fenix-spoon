Fenix Spoon 🥄 — airfoil, built from the widget packages

Same demo as the zero-dependency version, rebuilt on @fenix-spoon/client, <fs-geometry-2d> and <fs-viewer>. Drag the control points; the solve runs on every edit. All the interaction — keyboard operation, undo, insert/remove, contours, the probe readout, zoom and pan — comes from the packages, not from this page. Tick explore to hand the drag to the viewer instead of the editor: zoom into the suction peak, pan along the surface, hover to read the field. Nothing there re-runs the solver — it is all the arrays the page already has.

The widget bundles aren't built. Run npm --prefix client install && npm --prefix client run build, then reload. (The vanilla demo needs no build.)

Surface pressure, straight off the same result the field above came from — no second request. The saw teeth are the mock solver, not the plot. It masks a Cartesian grid, so the body is a staircase whose treads and risers sit at almost the same x/c and carry very different pressures; sorting them by chord station interleaves the two. Pick the FEniCSx solver, which meshes the profile itself, and the curve comes out smooth. Hover to read a point.
