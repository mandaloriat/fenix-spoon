Fenix Spoon 🥄 — airfoil, built from the widget packages

Same demo as the zero-dependency version, rebuilt on @fenix-spoon/client, <fs-geometry-2d> and <fs-viewer>. Drag the control points; the solve runs on every edit. All the interaction — keyboard operation, undo, insert/remove, contours, the probe readout — comes from the packages, not from this page.

The widget bundles aren't built. Run npm --prefix client install && npm --prefix client run build, then reload. (The vanilla demo needs no build.)
