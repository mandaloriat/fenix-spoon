Fenix Spoon 🥄 — a lift polar, swept from the browser

One study object, several solves, one curve. The page keeps its airfoil and its sweep on the server under stable ids and names them instead of resending them — which is what protocol 1.10 and 1.11 added, and what makes the second run of a sweep cost nothing. Edit the profile and the geometry gets a new revision; widen the angle range and only the new angles are solved — the grid is anchored at the lower end, so extending it reuses everything already computed.

The widget bundles aren't built. Run npm --prefix client install && npm --prefix client run build, then reload.

Drag a control point to change the section. Each edit writes one revision of the same geometry object — the sweep names the design, the design names the geometry, and nothing here resends an outline.
