Fenix Spoon 🥄 — demos

Browser front-ends talking to a FEniCSx-backed simulation server over the Fenix Spoon wire protocol.

  • Airfoil — 2D potential flow

    Drag the control points of an airfoil and watch the flow field update. Built from the published packages: @fenix-spoon/client, <fs-geometry-2d> and <fs-viewer>. Needs npm --prefix client run build first.

  • Airfoil — zero-dependency version

    The same problem in one self-contained HTML file with no build step and no packages — the reference implementation of the protocol, and the thing to read when you want to see exactly what goes over the wire.

  • Solenoid — 2D magnetostatics

    Resize an iron core inside a current-carrying coil and watch the flux redistribute. Demonstrates the regions2d geometry (multiple material regions), per-region physics on a tagged FEM mesh, and field-line contours.

  • Heat sink — conduction with convective cooling

    Add fins to an aluminium heat sink and watch the chip temperature fall — about 5× from none to twelve. The one demo whose controls are generated from the solver's params_schema rather than written by hand, so a solver that gains a parameter gains a slider here for free. Also shows a solver that treats the background as a boundary condition instead of a region: the air is never solved, and the result's mask says so.

  • Lift polar — a parameter sweep, driven from the page

    Sweep the angle of attack and get a curve instead of a picture. The only demo that keeps its geometry, design and study on the server under stable ids and names them rather than resending them, so a second sweep costs nothing and widening the range solves only the angles that are new. Shows the workspace and study routes added in protocol 1.10 and 1.11, and feeds <fs-plot> the study's Series1DData unmodified.

The vanilla pages are single self-contained HTML files with no build step, and they stay in the repository as the readable reference for what goes over the wire.
